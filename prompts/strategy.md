SBH 글로벌 금융 대시보드 스냅샷으로, ETF 바구니의 오늘 투자 전략 제언을 만든다.

입력 파일은 runtime/market-snapshot.json 하나다.
파일에 없는 가격, 등락, 배당수익률, 괴리율, 구성 종목, 일정, 사건을 만들지 않는다.
기준 숫자나 외부 기억을 가져와 "과열", "저평가", "역사적 고점"처럼 파일 밖 판단을 붙이지 않는다.
없는 항목은 빈 문장 대신 "대시보드에 없음"이라고 쓴다.
URL은 쓰지 않는다.

바구니는 다음 다섯 개다. 이름 문자열을 그대로 쓴다.
- S&P500
- QQQ
- Vanguard
- TIGER
- SCHD

각 종목의 limit 문장을 넘지 않는다.
QQQ는 나스닥 종합만 말하고, 나스닥100과 같다고 쓰지 않는다.
Vanguard는 S&P500과 같은 지수를 쓰되, 문장은 그 지수를 추종하는 ETF를 새로 담는 비중 조절로 쓴다. S&P500 문단과 같은 문장을 복사하지 않는다.
TIGER는 기초지수와 달러/원만 말한다.
SCHD는 가격을 쓰지 않는다. 사용자가 적은 SHUD는 SCHD다.

우선순위는 ETF 투자 동향, 핵심 경제 지표, 채권 동향이다.
뉴스 브리핑의 한 줄 요약보다 길게 쓴다.
개인 영향과 다음 행동은 각 두 문장 이상이다.
다음 행동에는 오늘 확인할 것과 한 번에 몰아서 사지 않을지를, 파일의 등락 방향으로만 연결한다.
매수 수량, 목표 가격, 손절 가격은 만들지 않는다.

지표 블록은 VIX, 달러지수, 환율, 원자재, CPI, 바구니 밖 지수를 ETF 보유와 신규 매수에 연결한다.
채권 블록은 미국 국채금리와 정책금리만 다룬다.
changePct는 상대 변화율이다. 국채 절대 변화는 dayChangePctPoint만 %포인트로 말한다.

출력은 아래 JSON 하나만 BEGIN_JSON 과 END_JSON 사이에 둔다.
설명, 마크다운 펜스, 도구 호출은 하지 않는다.
nextActions는 3개 이상 5개 이하다. ETF를 먼저 둔다. 문장 안에 콜론을 넣지 않는다.

BEGIN_JSON
{
  "stance": "오늘 바구니를 대하는 한 줄 태도",
  "etf": [
    {
      "name": "S&P500",
      "move": "대시보드 수치로 본 움직임",
      "volatility": "오늘 변동이 의미하는 흔들림",
      "investorImpact": "이 ETF를 시작하려는 개인에게 미치는 영향. 두 문장 이상.",
      "action": "다음 확인 또는 실행 보류. 두 문장 이상."
    }
  ],
  "indicators": {
    "summary": "핵심 지표가 바구니에 주는 의미. 두 문장 이상.",
    "investorImpact": "개인 투자자에게 미치는 영향. 두 문장 이상.",
    "action": "다음 확인 행동. 두 문장 이상."
  },
  "bonds": {
    "summary": "국채금리와 정책금리가 바구니에 주는 의미. 두 문장 이상.",

    "action": "다음 확인 행동. 두 문장 이상."
  },
  "nextActions": [
