# Meridian

아침마다 뉴스와 시장을 한 창에 모아 보는 브리핑이다. 왼쪽은 금융, 오른쪽은 국제정세다. 기사는 SBH News 피드에서 오고, 숫자는 공개된 공식 자료만 쓴다.

## 받아서 쓰기

이 저장소에서 ZIP을 받아 압축을 풀면, 그 폴더가 프로그램이다.

Node, Python, Edge가 먼저 깔려 있어야 한다. 폴더에서 `install-gemini.cmd`를 실행하면 뉴스 수집 패키지가 설치되고 `.env`가 생긴다. [Google AI Studio](https://aistudio.google.com/apikey)에서 무료 키를 받아 `.env`의 `GEMINI_API_KEY`에 넣는다.

`run-daily-gemini.cmd`를 한 번 실행해서 창이 뜨는지 본다. 매일 아침 7시 30분부터 밤 10시 30분까지 30분마다 돌리려면 `runtime\register-task-gemini.ps1`을 실행한다. 같은 이름의 예약이 이미 있으면 그 스크립트는 예약을 바꾸지 않고 멈춘다.

키는 로그에 남지 않는다. `.env`도 저장소에 올라가지 않는다.

## 이미 이 컴퓨터에서 돌고 있다면

글을 쓰는 쪽이 Cursor인 실행은 `run-daily.cmd`다. 작업 스케줄러에서 찾는 이름은 Meridian이다. 그 예약은 저장소에 없다. `runtime\task.xml`은 한 컴퓨터의 복사본이라 다른 PC로 가져가면 안 된다.

한 번 실행되면 이렇게 진행된다.

1. Cursor 로그인을 확인한다. 안 되어 있으면 다시 묻지 않고 멈춘다.
2. SBH News 피드를 동기화하고, 아직 안 읽은 기사만 가져온다.
3. 안 읽은 기사가 있으면 분류만 Cursor에 맡긴다. 그 호출에서 피드를 다시 받거나 읽음 처리하지 않는다.
4. `briefings\latest.md` 하나를 덮어쓴다. 날짜별 파일은 만들지 않는다.
5. 확인한 기사는 읽음 처리하고, 남은 수를 다시 센다.

기사가 없어도 브리핑 파일은 만든다. 뉴스 데이터베이스는 직접 수정하지 않는다.

## 실행이 끝나면

하루의 첫 성공은 아침 브리핑이고 창을 연다. 같은 날 이후에는 긴급한 이슈가 있을 때만 창을 연다. 없으면 본문을 유지한 채 조용히 끝난다. 다음 날 첫 실행이 브리핑을 새로 쓴다.

투자 문장은 `briefings\strategy.md`에만 둔다. 창이 열릴 때 금융 화면을 다시 읽고, 창 크기는 1280×740이다. 로그는 `logs\latest.log`다. 실패하면 `logs\last-failure.log`에도 남긴다.

`latest.md` 맨 위에는 마지막 시각, 성공인지 실패인지, 이번에 처리한 기사 수가 있다.

끝나는 코드는 0이 성공, 1이 도중에 실패, 2가 로그인 실패, 3이 20분을 넘긴 경우, 4가 이미 실행 중이라 건너뛴 경우다. 스케줄러는 4를 성공으로 본다. 동시에 두 번 돌지 않도록 `runtime\pipeline.lock`을 잡고, 그 잠금이 두 시간을 넘기면 이전 실행이 죽은 것으로 보고 지운다.

작업 스케줄러가 `run-daily.cmd`를 바로 실행하면 콘솔이 닫히면서 프로그램이 죽는다. 예약은 `runtime\probe.vbs`를 거쳐 실행한다. 아침 7시 30분에 시작해서 30분마다, 밤 10시 30분까지 반복한다. 그 시각에 컴퓨터가 꺼져 있으면 다음에 켜진 뒤 한 번 이어서 실행한다.

## 창에 나오는 금융 수치

맨 위는 S&P500, QQQ, Vanguard, TIGER, SCHD다. SCHD는 SHUD라고 적어도 알아듣는다. 각 칸은 그 종목과 가장 가까운 지표가 최근 20거래일 동안 어느 쪽인지, 그래서 나눠 살지 말지만 말한다. 창을 열지 않는 실행에서도 숫자와 화면 파일은 갱신된다. 이미 열려 있는 창은 그때의 숫자를 유지한다.

키 없이 받는 자료는 FRED 공개 CSV와 Cboe 공식 CSV다. 미국 장이 끝나기 전에는 오늘 날짜가 나오지 않고, 발표가 늦은 환율 같은 지표는 발표된 날짜를 그대로 보여 준다. KRX, FMP, 한국투자증권 시세, 한국은행 ECOS는 키가 있어야 한다. 주문은 넣지 않는다.

폴더에서 이렇게 실행한다.

```text
python -m finance check
python -m finance backfill
python -m finance update
python -m finance validate
python -m finance snapshot
```

`backfill`은 공개 CSV가 주는 범위만큼 받는다. 키가 있는 일별 API는 최근 1년이다. 하이일드 스프레드 공개 CSV는 2023-10-16 이후만 내려와서, 그 이전은 FRED 키가 있어야 한다. 더 긴 국내 이력은 `python -m finance backfill --since 2010-01-04`로 받는다. `update`는 마지막 날짜 근처만 다시 받아 같은 행을 덮어쓰지 않는다. 저장 파일은 `finance\data\market.sqlite`다. 키 이름은 `.env.example`에 있다.
